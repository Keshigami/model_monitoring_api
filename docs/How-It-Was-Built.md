# How it was built

1. The original `main.py` had the right shape (Counter, latency Histogram, score Histogram, middleware, `/metrics`
   mount) but `/predict` returned `random.random()` after a random sleep, and `simulate_load.py` only printed status
   codes. The metric names and middleware were kept.
2. `/predict` now loads the churn bundle by path and runs the champion pipeline; the request body is a typed
   `Customer` with validated enum values and defaults, so a minimal JSON works and a wrong contract type is a 422.
3. Added `/drift`: a rolling `deque` of the last 200 inputs; for each numeric feature a z-score of the recent mean
   against the training mean with the standard error of the mean, |z| > 3 flags it; categoricals compare level shares.
4. Added `/simulate` (in-process traffic with an optional shift), `/summary`, `/health`, and the status page with stat
   tiles, a score histogram and the drift table; `simulate_load.py` fires 200 real HTTP requests and prints p50/p95/p99.
5. Tests train the churn model through its own venv if the bundle is missing, so the suite runs from a clean checkout.

## Tech stack
| Layer | Choice | Why |
|---|---|---|
| Language and runtime | Python 3.11 via uv | Same as the rest of the portfolio |
| Model or core logic | The churn champion pipeline from `../churn_predictor/models/churn.joblib` (scikit-learn 1.9) | The monitored model is a real one, not a random number |
| Interface | FastAPI + one HTML status page on `common/ui.css` | `/predict`, `/metrics`, `/drift`, `/health`, `/simulate` with OpenAPI docs for free |
| Data | Training statistics stored in the bundle; traffic generated by `random_customer()` | Drift needs the training means and stds; traffic is simulated |
| Tests | pytest + FastAPI TestClient (6 tests) | predict, validation, metrics text, drift numbers, shifted traffic flagged |

## Libraries
`fastapi` (routing, validation), `prometheus_client` (Counter, Histogram, `/metrics` ASGI app), `pydantic` (customer
schema with enum fields), `joblib` + `scikit-learn` (load and run the churn pipeline), `pandas` (one-row frames, drift
means), `uvicorn` (server), `requests` (load script), `httpx` (TestClient), `ruff`, `pytest`.
