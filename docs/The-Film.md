# The film

`demo/film.mp4` is 90 seconds in four chapters, made for engineers and project managers who have ninety seconds.

1. **What it does** (0 to 17 s): a terminal prompt runs the project's real first command and the response becomes a printed object. This report is from the running model. Then the stake: The inputs moved. The model kept answering. Who notices before a customer does?
2. **How it is built** (17 to 40 s): a paper model of the pipeline, stage by stage, with the reveal: GET /drift after 100 shifted requests, the one line of code that matters, the API call and the tests.
3. **The proof** (40 to 68 s): the real app, recorded. Fifty requests: served, p50, p99, drift status Fifty drifted requests: Tenure and TotalCharges flagged The raw /metrics text Prometheus would scrape
4. **The answer** (68 to 90 s): z 13.3, Tenure drift · 100 shifted requests · flagged above 3. Real model, real metrics. And it ships. One limit: Traffic is simulated. The window resets on restart. Then the prompt types `just setup && just up`.

`demo/film-60s.mp4` is the same without the proof chapter. `demo/demo.mp4` is the plain captioned walkthrough of the app.

Every number in the film comes from the project's own metrics, findings or a live response; nothing is drawn by hand. The film pipeline lives in the author's workspace, not in this repo.
